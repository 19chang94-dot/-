# 서울시 매장 도팅 지도 (Leaflet)

서울시 지도를 띄우고 매장명을 점(마커)으로 표시하는 최소 예제입니다.

## 기능

- 서울 중심 지도 표시
- `name`, `lat`, `lng` 컬럼을 가진 CSV 업로드
- 매장 점(도팅) 표시 + 팝업
- 매장명 검색 이동
- 샘플 데이터 버튼

## 실행 방법

정적 파일이라 아래 중 하나로 실행하면 됩니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## CSV 형식

아래 헤더를 포함한 CSV를 준비하세요.

```csv
name,lat,lng
강남점,37.4981,127.0276
홍대점,37.5563,126.9236
```
